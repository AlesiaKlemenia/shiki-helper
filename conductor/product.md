# Product Definition: Shiki-Helper

## Overview

**Shiki-Helper** — автоматизированный Telegram-бот для саб-мейкеров и релиз-групп, работающих с аниме-контентом. Бот интегрируется с официальным Shikimori API и Google Таблицами, чтобы отслеживать выход новых серий и поддерживать рабочий процесс команды в актуальном состоянии.

## Target Audience

Саб-мейкеры, переводчики и релиз-группы, отслеживающие выход серий аниме и ведущие рабочие таблицы выпущенных тайтлов.

## Core Value Proposition

- **Автоматический мониторинг** выхода новых серий через Shikimori GraphQL API без необходимости вручную проверять сайт.
- **Двусторонняя синхронизация** с Google Таблицами: бот читает рабочий список релизов и обновляет счётчик вышедших серий (колонка D).
- **Персональные дайджесты** с учётом часового пояса каждого участника — красивые, информативные сообщения с эмодзи и ссылками.
- **Принудительное обновление** по команде `/sync` — мгновенная проверка без ожидания расписания.

## Key Features

### MVP (Этап 1–4)
1. **Инфраструктурный каркас** — PostgreSQL / SQLite + Redis + SQLAlchemy 2.0 (async) + Alembic.
2. **Shikimori GraphQL клиент** — батчинг, rate-limiting (5 rps), exponential backoff при ошибках.
3. **Google Sheets клиент** — OAuth 2.0 авторизация, чтение/запись диапазона A2:D, batchUpdate.
4. **Бизнес-логика трекинга** — сравнение `episodesAired`, формирование дельты, генерация дайджеста.

### Phase 2 (Этап 5–6)
5. **Telegram UI на aiogram-dialog** — онбординг, настройки таймзоны/времени, пагинация тайтлов, FTS5 поиск.
6. **Sandbox / Shadow DB** — изолированный тестовый режим через `ContextVar` без риска повредить боевые данные.
7. **APScheduler** — динамическая регистрация задач, graceful shutdown, misfire_grace_time.
8. **Healthcheck-сервер** (`GET /health`) — предотвращение усыпления Render.com.
9. **Резервное копирование** — снапшот БД в Telegram-топик по расписанию.
10. **Recovery Alerts** — уведомления о перезапуске и восстановлении подключений.

## Success Criteria

- Бот корректно отслеживает вышедшие серии и отправляет дайджест в указанное время.
- Синхронизация с Google Таблицами работает без ошибок авторизации и потери данных.
- Все критические сбои (БД, Redis, Google OAuth) обрабатываются с graceful degradation и уведомлением администратора.
- Покрытие тестами для бизнес-логики (`tracker`, `digest`, `shikimori`, `sheets_sync`) ≥ 80%.
- Проект успешно разворачивается через `docker-compose up --build`.

## Out of Scope (v1)

- Мобильное приложение или веб-интерфейс.
- Поддержка манги или других типов контента Shikimori (только аниме).
- Публичный multi-tenant SaaS (только персональный/командный инструмент).
